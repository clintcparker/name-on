# feat: fix-install-channels — working package-manager install channels

## Summary

Both advertised package-manager install commands were broken: `dotnet tool install -g name-on` failed with "not found in NuGet feeds" and `brew install clintcparker/tap/name-on` failed with "Repository not found". The root cause was that release automation triggers on `v*` tags, but every release ever cut used `0.1.7+1`-style tags — so the pipeline never ran once, and nothing was ever published anywhere. This PR makes `v*` SemVer tags the documented and actual release procedure, wires the tag version into every built artifact, completes the pipeline (NuGet publish + Homebrew tap formula push with checksums), makes missing one-time setup fail loudly, and adds a channel-freshness verification workflow.

## Specification

[spec.md](../spec.md) — three user stories:

- **US1 (P1)**: `dotnet tool install -g name-on` installs from nuget.org and `name-on --version` reports the released version (FR-001, FR-010).
- **US2 (P2)**: `brew install clintcparker/tap/name-on` resolves the tap, installs a checksum-verified prebuilt binary per platform (FR-004).
- **US3 (P3)**: Cutting a release with the normal procedure reaches every channel with zero manual steps; drift or partial failure is reported to the maintainer, not discovered by a user (FR-005, FR-006, SC-003–SC-005).

Key constraints: one-time setup (secrets, tap repo) is manual by design and must fail loudly when absent (FR-009); 002's `verify-install-urls.yml` must keep passing unchanged (FR-008).

## Implementation

Key decisions from [plan.md](../plan.md):

- **Version flows from the tag only**: removed hard-coded `<Version>1.0.0</Version>` from `name-on-cli.csproj`; a `preflight` job derives `VERSION=${GITHUB_REF_NAME#v}` and passes it via `-p:Version` to publish and pack, so binary, nupkg, and formula cannot disagree (contract C4).
- **Loud preflight failure**: missing `NUGET_API_KEY` or `TAP_PUSH_TOKEN` kills the run in seconds with `one-time setup missing: <SECRET> (see docs/how-to/release.md)` (contract C6, FR-009).
- **Tap publishing without new tooling**: `install/homebrew/name-on.rb` template rendered with `sed` in a workflow step, committed to `clintcparker/homebrew-tap` via a fine-grained PAT.
- **Separate drift detection**: new `verify-install-channels.yml` (daily + post-release + dispatch) checks nuget.org, tap formula, and release assets exist and agree on version — kept separate from 002's URL verification so that workflow stays untouched (FR-008).
- **Idempotent re-runs**: `--skip-duplicate` on NuGet push, no-op formula commits, `softprops/action-gh-release` updates existing releases (contract C2).
